Présentation

L'IA agentique, expliquée simplement

Un agent ne se contente pas de répondre : il décide, utilise des outils et agit à ta place, de l'interface jusqu'aux services extérieurs.

Chatbot vs agent

Un chatbot répond, un agent agit

  • Chatbot : il te dit quoi faire. C'est toi qui fais.
  • Agent : tu lui donnes un objectif, il fait le travail.
  • Il enchaîne plusieurs actions jusqu'à ce que l'objectif soit atteint.

Ses propres décisions

Une boucle : observer, décider, agir, vérifier

  1. Observer : il regarde la situation (messages, données, écran).
  2. Décider : il choisit lui-même la prochaine action.
  3. Agir : il utilise un outil.
  4. Vérifier : il contrôle le résultat, et recommence si besoin.

Personne ne lui dicte chaque étape : il s'arrête quand l'objectif est atteint.

Ses outils

Des outils côté front, côté back, ou les deux

Front agir dans l'interface
Contrôler l'affichage, ouvrir un formulaire pour demander une info manquante, afficher une fenêtre de confirmation.
Back agir sur le système
Interroger la base de données, appeler une API, exécuter du code.

Chaque outil a un nom, une description et un contrat : l'agent sait quand et comment s'en servir.

Côté front

Il pilote la vue

  • Affichage : il ouvre un écran, met une info en avant, met la liste à jour.
  • Formulaire : il demande à l'utilisateur ce qui lui manque (un créneau, une adresse…).
  • Confirmation : il fait valider une action importante avant de la lancer.

Côté back

Il met à jour la data

  • Il lit et modifie la base de données directement.
  • Il appelle les API internes : créer une facture, changer un statut.
  • Plus rapide et plus fiable que de passer par l'écran.

Services extérieurs

Mail, SMS, plateformes : une seule prise, le MCP

  • Mail et SMS : prévenir le client, le prestataire, l'équipe.
  • API de plateformes : agenda, paiement, CRM, Notion, GitHub…
  • Grâce au standard MCP, chaque service se branche de la même façon : l'agent découvre ses outils tout seul.

Exemple complet

« Organise l'intervention du plombier »

  1. Le client écrit : « Fuite, dispo ce soir ? »
  2. L'agent décide d'un plan.
  3. Back : il vérifie les créneaux et réserve.
  4. Front : le tableau de bord se met à jour.
  5. MCP : SMS au client, mail au plombier.
  6. Il vérifie que tout est fait : objectif atteint ✓

À retenir

En une phrase

Un agent IA décide lui-même de ses actions et les réalise avec des outils : dans l'interface, dans les données, et dans les services extérieurs via le MCP.
  • Il décide : observer → décider → agir → vérifier.
  • Il agit : outils front (la vue) et back (la data).
  • Il se connecte : mail, SMS, plateformes, avec le standard MCP.
  • Pour aller plus loin : la présentation MCP
